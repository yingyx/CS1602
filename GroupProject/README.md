# MiniMatrix

Group project for **CS1602, Intro to Computers & Programming**.

A lightweight 2D matrix library implemented in pure Python, based on the starter code provided for the course assignment.

Collaborators: [@Szob8](https://github.com/Szob8), [@koi2006-jbx](https://github.com/koi2006-jbx).

## Files

* `minimatrix.py` — completed MiniMatrix implementation
* `main.py` — tests and examples
* `starter_code/` — original course-provided starter code
* `report.pdf` — project report
